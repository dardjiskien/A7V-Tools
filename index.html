Assemblage Mac / PC

Lightroom Classic → Photoshop

1

Préparer et synchroniser les RAW (.ARW)

Dans Lightroom Classic, corrige une photo (profil d'objectif, balance des blancs, exposition, hautes lumières) puis clique sur Synchroniser pour appliquer les réglages à toute la pile.

2

Ouvrir en tant que calques

Sélectionne toutes les vues de la série → clic droit → Modifier dans → Ouvrir en tant que calques dans Photoshop.

3

Aligner les calques (Focus Breathing)

Dans Photoshop, sélectionne tous les calques dans le panneau Calques, puis va dans Édition → Alignement automatique des calques (projection Auto).

4

Fusionner la netteté

Toujours avec tous les calques sélectionnés : Édition → Fusion automatique des calques → Empiler les images. Coche Tons et couleurs continus et Zones transparentes avec fond basé sur le contenu.

5

Recadrer et enregistrer

Recadre légèrement les bords si un liseré subsiste, puis fais Cmd + S (ou Ctrl + S) pour rapatrier le fichier TIFF fusionné dans ton catalogue Lightroom.

Icône directe sur ton iPhone

Cette application embarque son propre cache hors-ligne. Une fois ajoutée sur ton écran d'accueil, elle s'ouvre instantanément en mode avion ou sans réseau :

1 Ouvre l'adresse hébergée (GitHub Pages) dans Safari sur ton iPhone avec du réseau.
2 Appuie sur ••• à côté de la barre d'adresse → Partager → fais défiler → « Sur l'écran d'accueil ». Laisse Ouvrir comme app web activé → Ajouter.
3 Vérifie que la pastille en haut affiche Prêt hors-ligne : tu peux couper le réseau, l'icône fonctionnera partout.
